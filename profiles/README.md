# 설정 레시피

`mobile-starter.example.json`은 기본 Website 5개와 Open 1개를 설명하는 설정 레시피입니다. Stream Deck으로 가져올 수 있는 네이티브 프로필이 아닙니다.

[설정 가이드](../docs/mobile-setup.md)에 따라 별도 시험 프로필에서 수동으로 구성합니다. 검증한 뒤 앱이 내보낸 `.streamDeckProfile`은 개인 환경에서 보관하고, 공개할 때는 내부 주소·로컬 경로·계정·장치 정보가 없는지 별도로 확인합니다.

기존 실제 프로필을 이 예시로 덮어쓰지 않습니다.
